- 실행: 2026-10-20 16:33 KST, 구현 기준 `af02f56`
- 코드: [`eval/check_openai.py`](../check_openai.py), [원시 결과](openai_check.json)

- 모델 응답 버전: `gpt-4o-mini-2024-07-18`, `gpt-4o-2024-08-06`

## 경로와 조건

FastAPI TestClient의 ASGI `/chat/stream` 경로에서 실제 LangGraph, OpenAI HTTP API, 실제 MCP stdio 서버를 실행했다. 모니터링은 운영 데이터가 아닌 저장소의 모의 데이터이며 무작위 변동과 첫 조회 재시도를 포함했다. 브라우저·프록시는 포함하지 않았고 임시 SQLite를 사용했다. 기존 서버·DB·`.env`는 변경하지 않았다. 두 추적 플래그는 false였다.

검증 실행에만 최대 유료 호출 6회, 호출당 mini 700/quality 1,100 출력 토큰 상한을 적용했다. 앱의 기본 설정은 그대로다. 같은 조건의 원본 대조군이나 반복 측정은 없다.

## 답변 수동 검토

- 현재 CPU 98.8%·메모리 58.9%, 알림 CPU 91%·임계치 80%를 구분했다.
- 배포·트래픽 이력 및 반복 호출·배치 여부는 미수집으로 표시했다.
- CPU 고부하의 지속 여부나 배포 직후라는 조건이 충족될 때 확장·롤백을 검토하도록 안내했다.
- 원인을 확정하거나 조치를 실행했다고 서술하지 않았다. 다만 실제 지속시간을 측정하지 않았으므로 운영 판단에는 추가 자료가 필요하다.

자동 통과 기준은 응답 완료, 기대 이벤트, 등록 답변의 검증 합격, 미등록 답변의 유료 호출 0회다. 자연어 전체의 사실성을 자동 보장하지 않는다. 고정 데이터 Ollama 실험과 입력·모델·경로·워밍업·출력 상한이 다르므로 모델 속도 순위를 매기지 않는다.
