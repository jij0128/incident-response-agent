# 발표자료

- [Apple Pages 발표자료](incident-response-agent.pages): 가로 방향 12페이지. Mac Pages에서 본문과 비교표를 편집할 수 있다. 기존 발표자료 내용을 Pages 문서로 옮겼으며 발표 대본은 별도 파일을 따른다.
- [발표 PPTX](incident-response-agent.pptx): 기존 12장 자료. 각 슬라이드의 발표자 메모에 설명과 근거 링크를 포함했다.
- [발표 대본과 예상 질문](SPEAKER_NOTES.md)
- [전체 결과 보고서](../PROJECT_REPORT.md)
- [2일차 완료 상태·3일차 준비](../DAY2_STATUS.md)

문제 → 개선 사항 → 전후 비교 → 한계·배운 점 순서다. 발표 시간은 강의자료에서 고정 길이를 확인하지 못했으므로 대본의 6~8분은 연습용 제안이며 실제 배정 시간에 맞춰 조정한다.

Pages 파일은 Mac Pages 앱에서 저장·다시 열기와 12페이지 출력을 확인했다. Pages는 문서 형식이므로 PPTX의 슬라이드 전환이나 발표자 메모 대신 페이지와 별도 대본을 사용한다. 3일차에는 발표에 사용할 기기와 표시 방식으로 연습한다. 사용 글꼴은 Apple SD Gothic Neo다. 다른 환경에서 글꼴 대체가 일어나면 해당 환경의 한글 글꼴로 바꾼 뒤 다시 확인한다.

PPTX는 파일 구조·레이아웃을 검사하고 슬라이드별 렌더링을 확인했다. PowerPoint 앱에서 직접 열어 확인한 것은 아니다.

슬라이드의 화면 캡처는 실제 브라우저 확인 자료다. 5번 화면은 Ollama 응답이고, 10번은 별도의 실제 OpenAI API 검증 결과다. 서로 다른 실행의 모의 지표를 동일 실험의 수치로 해석하지 않는다. 관리자 0건 화면과 이전 모의 요청 2건 연동 검증은 프로젝트 설정·시점이 다르다.
