문제 → 개선 사항 → 전후 비교 → 한계·배운 점 순서다. 최신 안내에 따라 **개인별 5분**으로 발표한다. 발표는 **10월 22일 13:10부터**, 본인 자리에서 Zoom 화면 공유로 진행한다. 개인 순서는 별도 안내를 따른다. 대본은 설명 4분 30초와 화면 전환·지연 여유 30초로 구성했다.

Pages 파일은 Mac Pages 앱에서 저장·다시 열기와 12페이지 출력을 확인했다. Pages는 문서 형식이므로 PPTX의 슬라이드 전환이나 발표자 메모 대신 페이지와 별도 대본을 사용한다. 3일차에는 발표에 사용할 기기와 표시 방식으로 연습한다. 사용 글꼴은 Apple SD Gothic Neo다. 다른 환경에서 글꼴 대체가 일어나면 해당 환경의 한글 글꼴로 바꾼 뒤 다시 확인한다.

PPTX는 파일 구조·레이아웃을 검사하고 슬라이드별 렌더링을 확인했다. PowerPoint 앱에서 직접 열어 확인한 것은 아니다.

슬라이드의 화면 캡처는 실제 브라우저 확인 자료다. 5번 화면은 Ollama 응답이고, 10번은 별도의 실제 OpenAI API 검증 결과다. 서로 다른 실행의 모의 지표를 동일 실험의 수치로 해석하지 않는다. 관리자 0건 화면과 이전 모의 요청 2건 연동 검증은 프로젝트 설정·시점이 다르다.

## 제출 형식과 최신 반영 범위

최종 보고서는 외부에서 접근 가능한 링크로 **10월 22일 13:00까지** 제출한다. 발표 자료는 자율 선택이므로 별도 PPT가 필수는 아니다. 표지 정보는 **SKALA 광주 2반 / G065 / 정인제**다.

이번 최신 안내는 Markdown 결과 보고서와 5분 대본에 반영했다. 기존 Pages·PPTX 파일은 12페이지/장 본문을 유지했으며 표지 정보와 다크 테마 캡처는 갱신하지 않았다. 최신 표지는 결과 보고서 첫 화면을 사용하고 Pages는 설명 자료로 활용할 수 있다. 최신 다크 화면은 보고서의 연결된 캡처를 사용한다. 발표 전 이 순서로 Zoom 화면 공유를 연습한다.
