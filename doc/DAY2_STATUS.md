## 시연 순서

```text
1. payments-service 결제 응답이 느려지고 CPU가 치솟았어요, 원인 확인해주세요.
2. billing-service 응답이 느려요. 원인 확인해주세요.
3. payments-service와 billing-service 둘 다 응답이 느려요. 원인 확인해주세요.
```

추적이 꺼진 관리자 화면은 새 요청이 기록되지 않는 것이 정상이다. 기존 모의 연동 결과는 보고서로 설명한다. 시연을 위해 추적을 켜면 질문·답변·프롬프트·실행 정보가 LangSmith로 전송되므로 별도 전송 범위를 확인해야 한다. OpenAI 재시연은 실제 비용이 발생한다. 기존 캡처와 JSON 결과로 설명할 수도 있다.

실행 스크립트는 이전 포트 프로세스를 종료하고 DB를 초기화하므로 발표 직전에 무심코 재실행하지 않는다. 실행과 테스트 방법은 [README](../README.md)에 있다.
